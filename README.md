# steckercheck.de

Static site for https://steckercheck.de/ — Steckersolar 800 VA / 2000 Wp, sourced from EEG, BNetzA, MaStR.

No analytics, no Awin JS, no Google Fonts. Partner links only when a program has accepted; they belong on `balkonkraftwerk-kaufen.html` and must be labelled **Werbung**.

Public pages: `index.html`, `800-watt-2000-wp.html`, `balkonkraftwerk-kaufen.html`. Legal: `impressum.html`, `datenschutz.html` (noindex). Agents: `llms.txt`, `llms-full.txt`.

Deploy: zip the public files and replace-deploy the existing Cloudflare Pages project `steckercheck`.
